## Projects

- [Input Guard](input-guard) - A macOS menu bar utility that prevents selected audio devices from becoming the default input.
- [Battery Watch](battery-watch) - A macOS menu bar utility that warns when trusted iPhones or AirPods run low.
- [Cmd Tab](cmd-tab) - A macOS app switcher that always opens a window for the selected app.
